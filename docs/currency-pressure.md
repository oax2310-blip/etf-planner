# 원·달러 상대 통화강도

시나리오의 **원·달러** 항목에서 같은 분기의 한미 GDP·M2 증가율로 상대 통화압력을 계산한다. 계산 규칙은 `js/currency-pressure.js` 담당 함수 주석이 기준이다. 임의 점수·가중치를 사용하지 않고 개인 기록·가정 저장·시세에는 쓰지 않는다.

## 공식 원자료와 계열 확인

2026-10-12에 GitHub Actions에서 ECOS 인증과 아래 공식 계열의 실제 수집을 확인했다. 최근 11년 원자료를 조회하여 10년 추이의 전년 대비 계산에 필요한 이전 1년까지 확보한다. 월 자료는 부분 분기를 추정하지 않는다.

| 지표 | 공식 계열 | 기준 |
| --- | --- | --- |
| 한국 실질 GDP | ECOS `200Y104 / 1400` | 실질·계절조정 분기 수준, 십억원 |
| 한국 M2 | ECOS `161Y005 / BBHS00` | 2025년 말 개편 기준, 평잔·계절조정 월 수준, 십억원 |
| 한국 기준금리 | ECOS `722Y001 / 0101000` | 공식 월별 기준금리, 연% |
| 미국 실질 GDP | FRED `GDPC1` · BEA | 실질·계절조정 연율 수준 |
| 미국 M2 | FRED `M2SL` · 연준 | 계절조정 월평균 수준 |
| 실제 원·달러 환율 | FRED `EXKOUS` · 연준 | 월평균, 원/달러 |
| 미국 실효 연방기금금리 | FRED `FEDFUNDS` · 연준 | 월평균, 연% |

ECOS의 `161Y005`에서 `BBHS00`은 개편 M2이고, 같은 표의 `BBHS11`은 **참고용 구 M2**이다. 개편 M2는 2003년 10월부터 소급 제공되며, 구성 항목에서 MMF 지분과 수익증권의 차이를 확인했다. 구계열 `101Y003`, 중단된 FRED 한국 M2 `MYAGM2KRM189S`, OECD M3로 대체하거나 구·신계열을 연결하지 않는다. 미국 M2와 한국 M2는 금융상품 범위·만기 기준이 완전히 같지 않다.

한국 GDP도 ECOS 최신 원자료를 사용하며, 계절조정 분기 **수준**의 전년 대비를 계산한다. 미국의 전기 대비 연율 성장률과 혼동하지 않는다. 금리차는 미국 실효금리 월평균과 한국 기준금리의 공식 월별 값 3개를 각각 평균한 차이로, 금리의 성격·집계 기준 차이를 명시하고 통화압력에 합산하지 않는다.

## 자동 수집과 인증

인증키는 GitHub 저장소 **Settings → Secrets and variables → Actions**의 `ECOS_API_KEY`에만 보관한다. 브라우저·공개 소스·시나리오 저장에 넣지 않는다. `FRED_API_KEY`는 선택 사항이며 출처 갱신일 메타데이터 확인에 사용한다. FRED 원자료 CSV는 키 없이 조회한다.

`data/currency-sources.json`은 확인한 공식 코드·단위·항목 이름·정의·확인일을 지정한다. 수집기는 코드·항목 이름·단위를 확인하여 다른 계열이나 증가율 계열을 수준 자료로 잘못 사용하지 않는다. `node scripts/collect-currency-pressure.cjs --discover`는 ECOS 통계표 후보를 조회한다. 필요하면 `scripts/discover-ecos.cjs`의 공식 항목 조회 함수를 사용해 소급 기간과 정의를 검토한다.

`node scripts/collect-currency-pressure.cjs`가 실제 수집을 수행한다. `.github/workflows/currency-pressure.yml`은 **한국시간 월~금 오전 07:20**에 예약된다(UTC 일~목 22:20). 공식 계열 설정·수집기 변경이 main에 반영될 때와 Actions의 수동 실행 때에도 수집한다. GitHub 예약은 지정 시각보다 지연될 수 있다. 공개 경제통계 JSON만 커밋하고 Pages 빌드를 요청한다.

이 개발 환경에는 FRED·ECOS 호스트의 네트워크 허용이나 ECOS 인증키가 없으므로 실제 조회는 GitHub Actions에서 수행한다. 인증키를 개발 환경으로 가져오지 않고, 공개 데이터만 검토 브랜치에서 가져와 확인한다. 연결 점검에 쓰는 로그에는 공개 통계표·항목 메타데이터만 남긴다.

## 발표 지연·개정 처리

`releaseDate`(공식 발표일), `sourceUpdatedAt`(출처 갱신일), `fetchedAt`(성공한 조회), `lastAttemptAt`(마지막 시도)을 구분한다. 조회일은 한국시간으로 표시하고 원문의 발표일·출처 갱신일은 날짜를 유지한다. CSV와 ECOS StatisticSearch가 발표일을 제공하지 않으면 `releaseDate`는 `null`로 두고 ‘확인 안 됨’으로 표시한다. FRED API의 `last_updated`를 공식 발표일로 바꾸지 않는다.

실패 시 같은 정의·코드의 마지막 원자료만 유지하고 `error` 상태를 표시한다. 계열 설정이 바뀌거나 제거되면 이전 계열을 재사용하지 않는다. 성공 시 전 기간을 다시 조회해 개정을 반영하며 `revisedPeriods`·`lastRevisionAt`에 수정 감지 시점을 남긴다. `firstSeenAt`은 수집기가 처음 확인한 시각으로 공식 발표 시각과 다르다. 이전 원자료는 Git 이력에 남는다.

네 성장률과 전년 비교값을 모두 갖춘 최신 공통 분기만 판단에 사용한다. 최신 분기의 대기·결측 항목과 마지막 계산 가능 분기를 함께 안내하고, 공개 캐시의 갱신이 8일 이상 늦으면 지연을 표시한다. 통계의 대상 기간과 조회일은 다른 개념이다.

## 실제 자료의 사후 검증과 해석

2026-10-12 조회 자료에서 최신 공통 분기는 2026년 2분기이며 상대 통화압력은 약 **−0.86%p**이다. 10년 조회창에서 다음 관계를 확인했다. 화면의 수치는 자료·조회 기간 변경에 따라 다시 계산한다.

| 환율 비교 시점 | 유효 표본 | 상관계수 | 표본 내 R² |
| --- | --- | --- | --- |
| 같은 분기 환율의 전년 대비 | 39분기 | 0.331 | 0.110 |
| 이후 3개월 분기 평균 환율 변화 | 39분기 | 0.228 | 0.052 |
| 이후 12개월 분기 평균 환율 변화 | 36분기 | 0.095 | 0.009 |

현재 표본에서 이 지표가 중장기 환율을 강하게 설명한다고 보기는 어렵다. 방향 일치율은 사후 표본의 관측 비율이며 미래 예측 확률이 아니다. 예를 들어 이후 12개월 비교의 방향 일치는 26/36(72.2%)지만, 같은 표본에서 항상 환율 상승을 가정해도 25/36(69.4%)이다. 발표 당시 자료·발표 시점을 사용하지 않았으므로 이후 3·12개월 비교도 실시간 예측 성과로 해석하지 않는다. 전년 대비와 12개월 변화율은 기간이 겹쳐 독립 표본도 아니다.

MV = PY에서 유통속도·통화수요가 안정적이라는 조건 아래 통화량 증가와 실질성장의 차이는 물가압력과 관련될 수 있다. 양국 차이는 장기 상대가격 압력을 살펴보는 참고 지표지만, 구매력평가가 단·중기 환율을 보장하지 않는다. 통화량·환율의 역인과, 금리·자금흐름·위험회피·경상수지 등 공통 충격도 고려해야 한다.

예측력 검증에는 ALFRED 미국 빈티지와 한국은행 과거 발표본, 각 발표 시각을 확보해야 한다. 발표 후 이용 가능한 시점으로 시간순 학습·검증을 나누고, 환율 유지·단순 추세·한 방향 유지 기준모형과 표본 밖 성능을 비교한다. 중립 구간·금리차 가중치는 별도 검증 없이 핵심 계산에 추가하지 않는다.
