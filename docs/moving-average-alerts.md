# 기준선 휴대폰 알림

안드로이드 Chrome에서 플래너의 동기화를 연결하고 **알림 → 추가**로 원하는 종목과 선을 등록합니다. **알림 받기**를 눌러 브라우저 알림을 허용합니다. 다른 휴대폰이나 PC에도 알림을 받으려면 해당 기기에서 다시 연결합니다. 앱 설치나 페이지를 계속 열어 두는 작업은 필요 없습니다.

발송 준비는 비공개 데이터 저장소의 업데이트된 **KIS 시세 수집** 작업을 처음 실행할 때 완료됩니다. 연결 준비 중이면 작업이 끝난 뒤 플래너에서 동기화합니다. 발송 준비는 기존 `KIS_APP_SECRET`을 사용하는 수집 환경에서 처리하며, 플래너 화면에 증권사 비밀키를 입력하지 않습니다.

## 판정

기준선은 종가의 단순이동평균입니다. N일선은 최근 N거래일, N주선은 최근 N주봉, N개월선은 최근 N월봉이며 이번 주·달의 봉도 포함합니다. 1~400으로 설정할 수 있지만 상장 기간에 따라 봉이 부족하면 기다립니다.

현재 가격이 기준선 대비 설정한 ±허용 범위에 진입하면 한 번 알립니다. 예를 들어 기준선 100, 허용 ±0.5%이면 99.5~100.5에 들어올 때 알립니다. 계속 범위 안에 있으면 반복하지 않습니다. 범위를 벗어난 뒤 다시 들어오면 다시 알립니다. 범위 밖의 두 수집 가격이 기준선의 반대편에 있으면 중간 통과로 알립니다. 이미 알린 근접 구간을 벗어나는 순간에는 별도 알림을 반복하지 않습니다.

국내 장중 30분, 미국 장중 1시간 간격으로 수집합니다. 예약 실행 지연·휴장·네트워크 실패가 있을 수 있으며 순간적인 접촉을 감지하는 실시간 시세 알림은 아닙니다. 최신 가격·이동평균을 확보한 수집 시점만 비교합니다.

발송 실패는 해당 기기에만 재시도합니다. 같은 알림은 최대 24시간 동안 재시도하고, 삭제·중지·수정한 규칙의 이전 알림은 취소합니다. 서비스에서 만료된 기기라고 응답하면 재시도를 중지합니다. 발송 직후 기록 저장 전에 작업이 중단되면 같은 알림이 다시 도착할 수 있으며 휴대폰은 같은 이벤트 ID 알림을 묶어 표시합니다.

## 저장과 개인정보

규칙과 기기 구독은 기존 비공개 `etf-planner-data.json`의 `alerts`에 저장합니다. 발송 이력은 `etf-planner-alert-state.json`, 연결 공개키·상태는 `etf-planner-push.json`에 따로 저장합니다. 이 파일들을 공개 사이트 저장소에 올리지 않습니다.

웹 푸시는 표준 `aes128gcm`으로 알림 내용을 암호화합니다. 발송 서버는 내용을 만들고 수신 기기는 복호화하지만 푸시 중계서비스는 암호화된 내용을 전달합니다. 알림에는 종목·기준선·가격만 넣습니다. 잠금화면에서 숨기려면 안드로이드의 사이트 알림 설정을 바꿉니다.

VAPID 발송키는 수집 환경에서 한 번 생성하고 AES-GCM으로 암호화해 비공개 `etf-planner-push-key.json`에 보관합니다. 암호화키는 기존 Actions 비밀값에서 HKDF로 파생합니다. 증권사 키·토큰·VAPID 개인키는 휴대폰이나 푸시 중계서비스로 전송하지 않습니다. 구독 주소와 구독키도 로그에 출력하지 않습니다.

## 다시 연결하기

- 브라우저 알림을 차단했다면 사이트 설정에서 허용한 뒤 **알림 받기**를 다시 누릅니다.
- 브라우저의 사이트 데이터를 지우거나 휴대폰을 바꾸면 해당 기기에서 다시 연결합니다.
- 동기화 실패·기록 충돌이 표시되면 먼저 해결합니다. 기기에만 저장된 구독은 서버에 반영되기 전까지 연결 완료로 표시하지 않습니다.
- 만료된 연결이라고 표시되면 **알림 연결 확인**을 눌러 다시 연결합니다. 실패하면 브라우저 사이트 설정에서 알림을 초기화한 뒤 다시 연결합니다.
- 기존 `KIS_APP_SECRET`을 바꿀 때에는 저장된 발송키를 이전 비밀값으로 복호화하고 새 값으로 다시 암호화해야 합니다. 복호화가 실패하면 개인키를 자동 교체하지 않고 연결 준비 상태로 멈춥니다. 발송키를 의도적으로 교체했다면 각 기기에서 다시 연결해야 합니다.

**이 기기 알림 해제**는 이 기기의 브라우저 구독을 해지하고 비공개 기록에서 제거합니다. 모든 기기의 발송을 중단하려면 모든 규칙의 사용 체크를 끕니다.
