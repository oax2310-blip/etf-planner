# 매매 기준 휴대폰·PC 알림

안드로이드 Chrome이나 PC 브라우저(Chrome·Edge·Firefox·Safari)에서 플래너의 동기화를 연결하고 각 매매 화면의 가격 옆 **알림 ON**을 켭니다. 별도 기준가 입력은 필요 없습니다. 오른쪽 위 **알림**을 엽니다. **알림 받기**를 눌러 브라우저 알림을 허용합니다. 다른 휴대폰이나 PC에도 알림을 받으려면 해당 기기에서 다시 연결합니다. 연결한 기기마다 같은 알림이 옵니다. 앱 설치나 페이지를 계속 열어 두는 작업은 필요 없습니다.

알림을 누르면 알림 ID에 연결된 계좌·종목의 분할매도·분할매수·재매수 화면이나 달러선물 화면을 엽니다. 같은 코드나 비슷한 이름의 다른 계좌를 대신 선택하지 않습니다. 완료 회차의 접기·펼치기 상태는 바꾸지 않고, 한 줄로 접힌 달러선물 손절·재매수 영역만 펼친 뒤 종목 위치까지 스크롤하고 3초간 강조합니다. 직접 추가한 기준선 알림은 해당 규칙을 펼칩니다. 플래너가 열려 있으면 그 탭에서 이동하고, 닫혀 있으면 새로 엽니다. 자산·시나리오 탭은 그대로 두고 플래너를 엽니다. 데이터 복원·페이지 로딩·글꼴 준비·화면 복귀를 기다린 뒤 이동하며 매매 기록은 바꾸지 않습니다. 사용자가 직접 메뉴나 종목을 선택하면 대기 중인 알림 이동을 취소합니다. 기존 연결 기기는 플래너를 한 번 열면 새 이동 기능이 적용됩니다.

이미 수신한 ID 없는 옛 알림은 같은 코드가 하나뿐일 때만 찾을 수 있습니다. 대상 ID가 삭제되었거나 기록이 아직 없는 경우에는 다른 계좌로 이동하지 않고 기록 복원을 기다립니다.

PC는 보통 브라우저가 켜져 있을 때 받습니다(플래너 탭은 닫아도 됨). 브라우저가 꺼져 있던 동안의 알림은 다시 켤 때 아직 재시도 기간(최대 24시간) 안의 것이 옵니다. Windows에서 브라우저를 닫아도 받으려면 Edge(Windows 10 20H1 이상)로 연결하고 Edge 설정 → 시스템 및 성능의 ‘닫혀 있을 때 백그라운드 확장 및 앱 계속 실행’을 켜 둡니다. Edge는 창을 닫아도 Windows 알림 서비스로 사이트 알림을 받습니다. Chrome은 창을 모두 닫으면 꺼질 수 있어 이때는 다시 켤 때 받습니다. PC가 꺼져 있거나 절전 중이면 어느 브라우저도 받지 못합니다. Windows·Mac 알림 설정에서 해당 브라우저 알림이 꺼져 있거나 방해 금지(집중 모드)가 켜져 있으면 화면에 보이지 않습니다.

발송 준비는 비공개 데이터 저장소의 업데이트된 **KIS 시세 수집** 작업을 처음 실행할 때 완료됩니다. 연결 준비 중이면 작업이 끝난 뒤 플래너에서 동기화합니다. 발송 준비는 기존 `KIS_APP_SECRET`을 사용하는 수집 환경에서 처리하며, 플래너 화면에 증권사 비밀키를 입력하지 않습니다.

## 기존 기준과 연결된 알림

- 분할매도: 첫 매도와 1회차가 같은 스위치를 공유하고 각 회차를 따로 ON/OFF합니다. **전체 ON**은 모든 회차를 켭니다. 일반적인 하락 매도 계획은 현재가가 기준가 이하일 때, 상승 매도 계획은 기준가 이상일 때 감지합니다.
- 달러선물: 각 미완료 회차를 따로 ON/OFF하고 **전체 ON/OFF**로 한꺼번에 설정합니다. 계획 수정의 **기준선 전체 알림**은 변경한 시선·일선·주선·월선의 모든 회차에 적용합니다. 기존 기준선별 설정은 유지되며 회차별 선택이 우선합니다. 같은 가격 회차에 여러 계약이 있으면 알림을 켠 미완료 계약이 하나라도 있을 때 한 번 알립니다. 시작선·⅓·⅔ 가격에서 매수하고 다음 선에 도달하면 별도로 매수합니다. 계약 수가 있는 가장 가까운 보유 월물의 현재가가 회차 가격 이상일 때 감지하며 완료 회차는 제외합니다. 직접 입력 추가 구간은 기존처럼 기준가 이하입니다. [가격 3등분 안내](price-thirds.md)에 계산·수량 배분 규칙을 정리했습니다.
- 달러선물 손절 후 재매수: 신저점 손절 시작·각 손절 회차는 보유 근월물 환율이 기준가 이하일 때, 이동평균 반등 단계 회차는 기준가 이상일 때 알립니다. 직접 분할은 선택한 올라오면 매수(기준가 이상)·내려오면 매수(기준가 이하) 조건으로 알리며, 이번 계획에 배분한 미완료 계약만 대상으로 삼습니다. 이동평균·직접 분할 모두 평균 손절 환율보다 높은 회차는 알리지 않습니다. 절반 손절 한도와 판 계약 수를 복원하는 배분을 사용합니다. 단계 알림을 켜면 그 단계의 1·2·3차(단계 환율에서 다음 단계 환율까지 0·⅓·⅔ 지점) 중 배분된 회차(평균 손절 환율 이하 회차)를 알립니다. 재매수를 시작한 뒤에도 미완료 손절 회차와 부분 체결의 남은 계약은 계속 알립니다. 비운 반등 기준가의 추정값과 거기서 나온 회차 환율은 알림에 쓰지 않습니다.
- 재매수: 신저점 입력 옆 이탈 알림은 기준가 미만, 회차별 손절은 기준가 이하, 단계별 재매수 회차는 기준가 이상을 감지합니다. 단계 알림을 켜면 그 단계의 1·2·3차 회차 가격을 알리며(1차는 단계 기준가), 회차는 미완료·배분 금액 있음·실제 기준가에서 나온 가격 조건을 모두 충족해야 합니다. N선(60분봉 차트의 N이평선)·N일선 가격은 종목 코드가 있으면 시세로 채우고(N선은 60분봉을 다 받기 전엔 직접 입력), 비운 가격의 추정치는 알림에 쓰지 않습니다. 미국 종목은 달러 시세로 판정합니다.
- 완료 체크는 발송 대상에서 자동 제외합니다. 재매수를 시작하면 신저점 이탈 알림은 멈춥니다. ETF 재매수와 달러선물 모두 남은 손절 회차는 재매수 중에도 알립니다(재이탈). 재매수 기한 알림은 없습니다. OFF나 완료 체크는 발송 대기 중인 이전 알림도 취소합니다.
- 기준가를 고치면 자동 반영되며, 플래너를 닫아도 새 시세로 자동 기준가·회차 가격·재매수 배분을 화면과 같은 계산 함수로 계산합니다. 기준가를 고치거나 처음 켰을 때 이미 조건에 해당하면 다음 수집에서 한 번 알립니다. 같은 조건에 머물면 반복하지 않고 반대편으로 돌아왔다가 재도달하면 다시 알립니다.

## 미완료 매매 재알림

연결 알림(분할매도·분할매수·매수대기·달러선물·재매수)을 받은 뒤 그 회차를 아직 완료 체크하지 않았고 시세가 여전히 같은 조건이면 다시 알립니다. 별도 설정은 없습니다.

회차 알림을 꺼 둔 매매 회차(분할매도·분할매수·달러선물 매수·손절·재매수)도 도달한 뒤 체결하지 않았으면 재알림합니다. 도달한 순간에는 알림을 보내지 않고, 그 도달 시각을 최초 시각으로 삼아 아래 일정대로 보냅니다(본문에 `최초 도달 … 알림 꺼짐`). 알림을 받은 뒤 끄거나 다시 켜도 재알림 일정은 이어집니다. 신저점 이탈·매수대기처럼 체결로 끝나지 않는 알림은 켜 둔 동안만 재알림합니다.

분할매수는 계획의 앞 회차 가격에 도달한 뒤 다음 회차 알림을 허용합니다. 체결 완료를 기다리지는 않으며, 알림 OFF 회차도 가격 도달을 확인합니다. 선행 미도달 중에는 후행 최초·재도달·미체결 재알림과 발송 대기를 막고, 이전에 순서를 건너뛰어 생성된 후행 재알림도 정리합니다. 정상 도달한 순서는 이후 가격 하락으로 취소하지 않습니다. 완료 회차는 순서에서 제외하고 매수대기는 별도로 판정합니다.

| 최초 알림 이후(한국 시간 날짜) | 재알림 |
|---|---|
| 당일 | 없음(기존 최초 알림만) |
| 1일 뒤 | 오전 9시~오후 8시 1회 |
| 2일 뒤부터 | 매일 오전 9시~12시 1회, 오후 2시~8시 1회 |

- 아래를 모두 충족할 때만 보냅니다: ① 회차 미완료 ② 이번 수집의 유효 시세가 최초 알림과 같은 조건(현재 기준가 기준) ③ 해당 날짜·시간대 ④ 그 시간대에 같은 회차를 아직 보내지 않음. 가격이 조건을 벗어나면 그 수집만 건너뛰고, 다시 충족하면 같은 일정으로 이어집니다. 건너뛴 재알림을 모아 보내지 않으며 최초 알림 날짜·기록·알림 항목은 그대로입니다.
- 별도 예약 실행 없이 기존 수집 시각에 판단합니다. 국내 주식·ETF는 09:20~15:20 장중 수집, 미국 주식은 한국 낮의 지난 정규장 확정 종가(같은 종가는 같은 날 오전→오후만, 휴장 다음 날·주말에는 반복하지 않음), 달러선물은 기존 알림 허용 시간의 새 시세, 비트코인은 매 수집 시세를 씁니다. 조회 실패·지난 시세·비트코인만 받은 수집에서는 보류합니다.
- 완료 여부는 발송 서버가 비공개 데이터 저장소에 동기화된 플래너 기록으로 판단합니다. 발송 직전에 저장소의 최신 기록을 다시 확인해 그사이 다른 기기에서 기록이 바뀌었으면 이번 재알림을 보류합니다. 동기화되지 않은 체크(오프라인·동기화 충돌 대기)는 서버가 알 수 없으므로 동기화 완료 표시를 확인하세요. 알림을 읽거나 알림내역을 여는 것만으로는 멈추지 않습니다.
- 완료 체크·계획 삭제나 회차가 더 이상 없으면 멈추고 대기 중인 재알림도 취소합니다. 알림 OFF는 매매 회차의 재알림을 멈추지 않으며, 끄기 전에 대기하던 최초·재도달 알림만 취소합니다. 기준을 직접 고치면 기존처럼 새 조건으로 한 번 알리고 새 회차로 셉니다. 회차·종목·매수·매도마다 따로 판단합니다.
- 같은 수집에서 같은 종목·같은 매매 종류(분할매도·분할매수·재매수·달러선물)의 재알림이 여러 회차이면 알림 한 건으로 묶어 보냅니다. 화면 순서상 첫 회차 이름으로 보내고 본문에 `외 N개 회차도 도달·미체결`을 붙이며, 묶인 회차도 그 시간대의 재알림을 받은 것으로 셉니다.
- 가격이 조건을 벗어났다가 다시 도달할 때의 기존 재도달 알림은 그대로 보내며, 그 시간대의 재알림 1회를 대신합니다. 미국 기준 한국장 재알림도 같은 시간대의 재알림을 대신합니다.
- 알림내역에는 같은 회차의 최초 알림과 재알림·재도달 알림이 항목 하나로 보입니다. 당시 조건·가격은 최초 알림 그대로이고 재알림 횟수와 마지막 발송 시각만 갱신합니다. 이미 읽은 항목도 그 뒤에 재알림이 오면 다시 **읽지 않음**과 알림 배지로 보이며, 열거나 읽음 표시하거나 재알림 푸시를 누르면 읽음이 됩니다. 재알림을 눌러도 같은 종목·회차로 이동합니다. 이 기능 이전에 따로 쌓인 알림은 회차 구분 정보가 없어 자동으로 합치지 않습니다.
- 적용 전에 이미 보낸 알림은 서버에 최초 발송 시각·회차 기록이 없어 재알림 대상이 아닙니다. 적용 뒤 새로 보내는 최초 알림(재도달 포함)부터 재알림합니다.

## 미국 기준 한국장 재알림

미국 ETF를 기준으로 국내 ETF를 거래한다면 **알림 → 미국 기준 한국장 재알림**을 켭니다. 기본은 OFF이며 기존 알림 ON/OFF·기기 연결과 별도로 저장합니다.

밤사이(한국 시간 18:00~다음 날 09:20 전) 발생한 미국 종목 신호만 한국장 오전 **09:20 이후 첫 국내 조회(보통 09:45쯤)**에 한 번 더 보냅니다. 같은 기준에서 여러 신호가 발생하면 마지막 신호만 재알림합니다. 새 신호가 없으면 추가 알림도 없습니다. 국내 종목·달러선물·비트코인 신호는 대상이 아닙니다. 기준을 OFF·삭제·수정하거나 완료 처리하면 대기 중인 재알림도 취소합니다. 이미 발송된 원래 알림은 그대로입니다.

주말·한국장 휴장일에는 보내지 않습니다. 오늘 실제 거래가 시작된 국내 대표 ETF의 일봉과 거래량을 확인한 오전에만 발송하며, 조회 실패 시 다음 오전 수집에서 다시 확인합니다. 주말·휴장일을 지나 다음 한국장까지 신호를 보관하되 3일 이상 지난 신호는 취소합니다. 예약 실행 지연을 고려해 09:20~12:00 전까지만 발송·재시도합니다.

재알림은 미국 신호를 다시 알려주는 것으로, 국내 ETF의 실시간 가격을 재판정하지 않습니다. 알림에 **신호 당시 가격·미국 시세 기준일·감지 시각**을 표시합니다. 기존 수집 작업과 같은 웹 푸시를 사용하며 그날 첫 국내 장중 실행에서 함께 보냅니다. GitHub 예약 실행은 몇 분~수십 분 늦어질 수 있습니다.

## 직접 추가한 기준선의 판정

**알림 → 직접 추가 알림 (선택) → 추가**에서 계획 외의 종목·기준선을 등록합니다. 비트코인은 종목 코드에 `BTC-USD`를 넣습니다(Coinbase 달러 시세). `BTC`는 미국 ETF 심볼이라 비트코인이 아닙니다.

기준선은 종가의 단순이동평균입니다. N일선은 최근 N거래일, N주선은 최근 N주봉, N월선(기록 이름 `N개월선`)은 최근 N월봉이며 이번 주·달의 봉도 포함합니다. 비트코인은 주말에도 거래하므로 N일선은 최근 N일이고, 일봉은 UTC 0시(한국 시간 오전 9시)에 바뀝니다. 주봉(월~일)·월봉은 그 일봉을 묶어 만듭니다. 1~400으로 설정할 수 있지만 상장 기간에 따라 봉이 부족하면 기다립니다.

현재 가격이 기준선 대비 설정한 ±허용 범위에 진입하면 한 번 알립니다. 예를 들어 기준선 100, 허용 ±0.5%이면 99.5~100.5에 들어올 때 알립니다. 계속 범위 안에 있으면 반복하지 않습니다. 범위를 벗어난 뒤 다시 들어오면 다시 알립니다. 범위 밖의 두 수집 가격이 기준선의 반대편에 있으면 중간 통과로 알립니다. 이미 알린 근접 구간을 벗어나는 순간에는 별도 알림을 반복하지 않습니다.

국내 주식·ETF 알림은 평일 **09:20부터 15:20 전까지**입니다. GitHub 예약 실행이 보통 25~35분 늦게 시작해(2026-10-13~23 실측 13~41분), 국내 장중 수집 12회를 09:15~14:28에 28~30분 간격으로 예약해 두었습니다. 그래서 첫 조회는 보통 09:45쯤, 마지막 조회는 41분 늦어도 15:10 전에 시작합니다. 개장 후 20분과 종가 동시호가 시간은 건너뜁니다. 제외 시간의 시세는 알림 판정 이력을 바꾸지 않으며, 국내 알림 재시도·푸시 보관 기간도 15:20에 끝납니다. 09:10·09:40·15:40 예약 실행 자체를 없애 평일 3회 줄였으므로, 실행당 1분 청구 기준 월 약 60~69분을 아낍니다. 국내 장중 작업이 09:20 전에 시작하거나 15:20 이후로 지연되면 조회·발송을 건너뜁니다.

비트코인은 국내장·미국장 수집과 같은 Actions 작업에서 함께 조회합니다. 09:10·09:40·15:40 예약 실행을 없애면 **비트코인 조회도 평일 3회 줄어듭니다**. 그 시간에 비트코인만 받는 대체 작업을 만들지는 않습니다. 비트코인 조회 횟수를 유지하려고 같은 예약을 남기면 실행 횟수 절감은 없습니다. 시간 조건에 따라 이미 시작한 작업을 건너뛰어도 분 단위 사용량은 남으며, 위 절감 계산은 예약 실행 자체를 제거하는 것에 대한 계산입니다.

종가와 비트코인은 같은 작업에서 받습니다. **16:40에는 국내 종가·비트코인, 06:40에는 미국 종가·비트코인**을 함께 수집합니다. 19:40은 비트코인 전용이며, 16:40 예약을 여기에 합쳐 없애는 변경은 포함하지 않습니다.

**16:40 종가 수집은 유지**합니다. 이동평균·평가액을 확정 값으로 갱신하기 위한 것이며 국내 주식 알림은 보내지 않습니다. 미국 장중은 기존 1시간 20분 간격(23:10·00:30·01:50·03:10, 그 뒤는 06:40 마감 후 확정 값)입니다. 비트코인은 이 수집 때마다 함께 받고, 평일 저녁 19:40과 주말(토 09:40 ~ 월 06:40)에는 3시간마다 비트코인만 받습니다. 예약 실행 지연·휴장·네트워크 실패가 있을 수 있으며 순간적인 접촉을 감지하는 실시간 시세 알림은 아닙니다. 최신 가격·이동평균을 확보한 수집 시점만 비교합니다.

달러선물 알림은 한국시간 정규장 **09:15부터 15:15 전까지**, 야간장 **18:30부터 익일 05:30 전까지**입니다. 각 장의 실제 개장 후·폐장 전 30분을 제외합니다. 야간장 휴장 여부는 개시일로 판단하므로 금요일에 시작한 장은 토요일 새벽에도 알림을 허용합니다. 만기 월물의 최종거래일에는 **11:00 전까지**만 허용하며 해당 월물은 그날 야간장에서 제외합니다. 다른 월물은 일반 시간을 따릅니다. 거래일·휴장일은 KIS 개장일 조회를 하루 단위로 캐시해 확인하며, 달력을 확인할 수 없거나 24시간이 지나면 달러선물 알림을 차단합니다. 거래소의 특별 시간 변경·야간 휴장 공지는 발송 서버의 세션별 예외 설정에 반영합니다. 기준: [KRX 미국달러선물 계약명세](https://www.krx.co.kr/contents/OPN/01/01040601/OPN01040601.jsp), [KRX 야간시장 안내](https://www.krx.co.kr/contents/OPN/01/01041402/OPN01041402.jsp)(조회 2026-10-12).

달러선물의 제한시간에 처음 감지한 조건은 발송을 보류합니다. 허용시간의 새 시세에서 여전히 조건을 충족하면 한 번 알리고, 조건을 벗어났으면 알리지 않습니다. 예를 들어 1,300원 이하 알림은 허용시간에 확인한 가격이 1,300원 이하일 때 발송하며, 1,300원 초과로 올라왔으면 발송하지 않습니다. 이미 알린 조건이 계속 유지될 때는 중복 발송하지 않고, 조건이 해제된 뒤 다시 충족될 때 기존 규칙대로 알립니다. 오래된 시세나 이전 알림 내용을 그대로 재생하지 않으며, 조회 실패 시 다음 정상 수집에서 다시 확인합니다. 실패한 발송도 같은 장의 알림 허용시간 안에서만 재시도하고 푸시 보관 기간을 해당 장의 제한 시각까지로 줄입니다. 기존 수집 예약·종가 및 이동평균 갱신은 유지합니다.

발송 실패는 해당 기기에만 재시도합니다. 같은 알림은 최대 24시간 동안 재시도하며 국내 주식·ETF는 당일 15:20까지, 달러선물은 해당 장의 알림 종료 시각까지만 재시도합니다. 삭제·중지·수정한 규칙의 이전 알림은 취소합니다. 서비스에서 만료된 기기라고 응답하면 재시도를 중지합니다. 발송 직후 기록 저장 전에 작업이 중단되면 같은 알림이 다시 도착할 수 있으며 휴대폰은 같은 이벤트 ID 알림을 묶어 표시합니다.

## 저장과 개인정보

오른쪽 위 **알림**은 알림내역을 엽니다. 내역 화면의 **알림 설정**에서 기존 ON/OFF·기기 연결·직접 추가 알림을 설정합니다. 전체/읽지 않음 필터, 개별 읽음·모두 읽음, 개별 삭제·확인 후 전체 삭제를 지원합니다. 종목명·발생 시각·조건·당시 가격·기준값은 알림 이벤트의 스냅샷이며, 계획이나 시세를 나중에 바꿔도 과거 내용은 바뀌지 않습니다. 이동은 기존 ruleId 기반의 정확한 종목 찾기·필요한 영역 펼침·강조 경로를 사용합니다. 삭제된 종목은 다른 계좌로 대체하지 않고 내역에 안내합니다.

앱을 닫은 동안 받은 푸시는 브라우저 IndexedDB 수신함에 먼저 저장하고, 페이지가 열리면 기존 플래너의 `alertHistory`로 옮깁니다. 새 발송 이벤트는 기존 비공개 `etf-planner-alert-state.json`의 `history`에 발송 대기·판정과 같은 체크포인트로 기록합니다. 플래너가 기존 `etf-planner-data.json`에 이벤트 ID를 저장한 뒤에만 발송 쪽 수신함을 정리하므로 미수신 기기도 동기화로 내역을 받습니다. 재시도·여러 기기 수신은 동일 ID로 합치고, 읽음은 유지하며 삭제 ID는 재등장을 막습니다. 알림내역만 자동 병합하고 거래 기록의 충돌 선택은 기존 정책을 유지합니다. 내역·읽음·삭제 ID는 기존 JSON 백업·복원·충돌 복구 기록에도 포함됩니다. 기존 평가 이력이나 발송 대기 알림을 과거 내역으로 변환하지 않습니다.

연결 알림의 ON/OFF는 기존 비공개 `etf-planner-data.json`의 해당 계획·기준선·달러선물 회차·재매수 단계의 `notify`에 저장합니다. 달러선물의 회차별 `notify`는 직접 알림을 바꿀 때만 저장하며, 없는 회차는 기존 기준선·전체 설정을 따릅니다. 별도 기준선 규칙과 기기 구독은 같은 파일의 `alerts`에 저장합니다. 수집 작업의 `etf-planner-linked-alerts.json`은 계산 중에만 생성하며 커밋하지 않습니다. 발송 이력은 `etf-planner-alert-state.json`, 연결 공개키·상태는 `etf-planner-push.json`에 따로 저장합니다. 이 파일들을 공개 사이트 저장소에 올리지 않습니다.

수신 기기는 알림 제목을 **분할매도 알림 · 종목명**처럼 종류와 종목명으로, 본문은 발송 본문에서 앞의 종목 코드만 빼고 보여 줍니다(재알림은 **분할매도 재알림**, 한국장 재알림은 **분할매도 한국장 재알림**). 종목명은 발송 이름(분할매도 카드 이름·재매수 이름·자산 배분 종목 이름)을 쓰고, 코드만 온 알림은 이 기기의 계획 이름이나 자산 배분·재매수의 같은 코드 이름으로 바꿉니다. 이 이름표는 플래너를 열 때 브라우저 IndexedDB에만 저장하며(이름·코드만, 동기화하지 않음) 찾지 못하면 코드를 보입니다. 같은 이름이 다른 코드에도 쓰이면 `이름 (코드)`로 표시합니다. 알림내역도 같은 이름과 종류(예: 재매수 · 손절)를 표시하지만 저장된 알림 스냅샷과 발송 서버의 알림 ID·규칙·이동 주소는 그대로입니다.

웹 푸시는 표준 `aes128gcm`으로 알림 내용을 암호화합니다. 발송 서버는 내용을 만들고 수신 기기는 복호화하지만 푸시 중계서비스는 암호화된 내용을 전달합니다. 알림에는 종목·기준선·가격만 넣습니다. 잠금화면에서 숨기려면 안드로이드의 사이트 알림 설정을, PC에서는 브라우저·운영체제 알림 설정을 바꿉니다.

VAPID 발송키는 수집 환경에서 한 번 생성하고 AES-GCM으로 암호화해 비공개 `etf-planner-push-key.json`에 보관합니다. 암호화키는 기존 Actions 비밀값에서 HKDF로 파생합니다. 증권사 키·토큰·VAPID 개인키는 휴대폰·PC나 푸시 중계서비스로 전송하지 않습니다. 구독 주소와 구독키도 로그에 출력하지 않습니다.

## 다시 연결하기

- 브라우저 알림을 차단했다면 사이트 설정에서 허용한 뒤 **알림 받기**를 다시 누릅니다.
- 브라우저의 사이트 데이터를 지우거나 휴대폰·PC를 바꾸면 해당 기기에서 다시 연결합니다.
- 동기화 실패·기록 충돌이 표시되면 먼저 해결합니다. 기기에만 저장된 구독은 서버에 반영되기 전까지 연결 완료로 표시하지 않습니다.
- 만료된 연결이라고 표시되면 **알림 연결 확인**을 눌러 다시 연결합니다. 실패하면 브라우저 사이트 설정에서 알림을 초기화한 뒤 다시 연결합니다.
- 기존 `KIS_APP_SECRET`을 바꿀 때에는 저장된 발송키를 이전 비밀값으로 복호화하고 새 값으로 다시 암호화해야 합니다. 복호화가 실패하면 개인키를 자동 교체하지 않고 연결 준비 상태로 멈춥니다. 발송키를 의도적으로 교체했다면 각 기기에서 다시 연결해야 합니다.

**이 기기 알림 해제**는 이 기기의 브라우저 구독을 해지하고 비공개 기록에서 제거합니다. 모든 기기의 발송을 중단하려면 각 종류의 **전체 OFF**와 신저점 이탈 스위치, 별도 기준선 규칙의 사용 체크를 끕니다.
