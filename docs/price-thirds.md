# 이동평균선 사이의 3등분 매수

달러선물 추가매수, 이동평균선 돌파 분할매수, 손절 후 재매수는 시작선 가격을 포함한 세 회차를 사용합니다.

시작 가격을 P, 다음 선 가격을 Q라고 하면 매수 가격은 P, P + (Q−P)/3, P + 2(Q−P)/3입니다. Q는 다음 선의 도달 매수입니다. 예를 들어 32일선이 1,350원이고 42일선이 1,380원이면 32일선 구간에서 1,350·1,360·1,370원, 42일선에서 별도로 1,380원에 매수합니다. 인접 구간의 경계에 주문을 두 번 만들지 않습니다.

| 차트 | 저장 이름 | 입력 예 |
| --- | --- | --- |
| 시선 · 60분봉 | N선 | 32선, 32시선 |
| 일선 | N일선 | 32일선 |
| 주선 | N주선 | 32주선 |
| 월선 | N개월선 | 32개월선, 32월선 |

기본 기간은 각 시간축의 25·32·42·60·80·125·150선입니다. 달러선물의 추가 구간은 기간 1~400과 시간축을 지정할 수 있습니다. 같은 시간축에서 기간이 다음인 선을 찾으며, 다음 선 기준가가 없거나 현재 선 이하이면 도달 매수만 계획합니다. 기준가를 알게 되면 중간 회차를 계산합니다.

달러선물은 구간의 계획 계약 수를 세 회차에 배분합니다. 계약 수를 자동으로 늘리지 않으며, 세 회차 모두 계약을 배정하려면 미체결 계획 수량이 충분해야 합니다. 계약 수를 바꾸면 미매수 계약을 다시 배분하고 체결 계약의 회차·체결가·월물은 보존합니다. 새 시세가 다음 선 가격만 바꿔도 이전 구간의 미매수 가격과 예상 손익을 다시 계산합니다.

분할매수는 시선·일선·주선·월선을 전체 또는 시간축별로 선택합니다. 기존 시선+일선 계획과 사용자 지정 단계는 수정 창을 열어도 선택이 보존됩니다. 목표가가 다음 선과 같으면 그 가격의 마지막 회차는 한 번만 만듭니다. 목표가 이상의 가격에는 배분하지 않습니다.

재매수는 기존의 평균 손절가 한도와 첫 체결 후 계획 고정 규칙을 유지합니다. 기존 단계 목록에는 **시·일·주·월선 추가**로 빠진 기본 선만 덧붙일 수 있으며 체결 기록과 기존 단계 순서를 보존합니다. 주식은 판 금액, 선물은 판 계약 수까지만 재매수합니다.

분할매도는 기존의 시작가~종료가 전체 구간과 지정한 분할 횟수를 유지합니다. 사용자가 요청한 점검 결과, 회차 기준가 계산과 연결 알림 계산은 같습니다.

화면과 서버는 `js/ma-ladder.js`의 같은 계산을 사용합니다. 알림은 현재가가 매수 회차 가격 이상일 때 도달로 판정하며 완료 회차는 제외합니다. 봉이 부족한 주선·월선은 이동평균을 만들어 내지 않고 직접 입력한 기준가를 유지합니다. 시세 수집 간에 도달했다가 되돌아온 가격은 놓칠 수 있습니다.

서버 연동 변경은 비공개 데이터 저장소의 `kis_prices.py`(시간축별 시세 수집), `compile_trade_alerts.cjs`(공통 계산 파일 로드), `ma_alerts.py`(새 알림 이름 검증)에 있습니다. 서버 변경을 먼저 반영한 후 플래너 변경을 반영해야 새 알림 이름이 거부되지 않습니다.
