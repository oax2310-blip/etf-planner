# ETF 분할매매 플래너

공개 페이지: https://oax2310-blip.github.io/etf-planner/

코드는 공개됩니다. 실제 보유 종목, 수량, 메모, 손익은 `index.html`이나 이 저장소에 적지 마세요. 사이트에서 입력한 기록은 현재 브라우저에 저장되고, 기기 간 동기화를 연결하면 내 GitHub의 **비공개 데이터 저장소**에도 저장됩니다.

## 기기 간 동기화 준비 (처음 한 번)

Google Cloud 같은 외부 서비스 설정은 필요 없습니다.

1. **비공개 데이터 저장소 만들기**: [github.com/new](https://github.com/new)에서 이름을 `etf-planner-data`로 하고 **Private**를 고른 뒤, **Add a README file**을 체크하고 **Create repository**를 누릅니다.
2. **토큰 만들기**: [Fine-grained 토큰 만들기](https://github.com/settings/personal-access-tokens/new)(Settings → Developer settings → Personal access tokens → Fine-grained tokens)에서 이름과 만료 기간을 정합니다.
   - **Repository access**: **Only select repositories**를 고르고 `etf-planner-data`만 선택합니다.
   - **Permissions → Repository permissions → Contents**: **Read and write**로 설정합니다.
   - **Generate token**을 누르고 값을 복사합니다. 토큰은 만들 때 한 번만 보이니 안전한 곳에 보관하세요.
3. 사이트 위쪽 **기기 간 동기화**에서 데이터 저장소(`oax2310-blip/etf-planner-data`)를 확인하고, 토큰을 붙여넣은 뒤 **연결**을 누릅니다. 다른 기기에서도 처음 한 번 같은 토큰을 넣으면 됩니다.

주의

- **토큰은 각 기기의 브라우저에만 저장합니다.** `index.html`, 이 저장소, 메모 어디에도 적지 마세요.
- 데이터 저장소는 반드시 **비공개**로 둡니다. 공개 저장소를 지정하면 사이트가 업로드를 거부합니다.
- 기록을 이 사이트 저장소(`etf-planner`)에 저장하지 마세요. 저장할 때마다 GitHub Pages가 다시 게시됩니다.

## 저장 방식

- 입력하면 먼저 현재 브라우저의 `localStorage`에 즉시 저장하고, 연결 중이면 잠시 뒤 데이터 저장소의 `etf-planner-data.json`에도 저장합니다. 저장할 때마다 데이터 저장소에 커밋이 하나씩 쌓이므로, 예전 기록은 그 저장소의 커밋 기록에서 볼 수 있습니다.
- 페이지를 열 때, 45초마다, 탭으로 돌아올 때 다른 기기의 변경을 확인합니다. 버튼을 누르지 않아도 됩니다.
- 한쪽만 바뀌었으면 자동으로 맞춥니다. 아무것도 입력하지 않은 새 기기는 저장소 기록을 바로 가져옵니다.
- 이 기기와 다른 기기에서 모두 바뀌었으면 어느 기록을 쓸지 묻습니다. 선택하지 않으면 자동 업로드를 멈추고 이 기기에만 기록합니다. 선택해 덮어쓴 기록은 그 기기에 복구용 JSON으로 보관하며, **동기화 설정 → 동기화 충돌 시 보관한 기록 내려받기**로 받을 수 있고, 같은 창 아래의 **JSON 파일 복원**으로 되돌릴 수 있습니다.
- 올리는 순간 다른 기기가 먼저 저장했다면 GitHub이 저장을 거절하므로, 덮어쓰지 않고 다시 확인합니다.
- 토큰이 만료되거나 틀리면 기록은 기기에 남고, 동기화 설정에서 새 토큰을 넣으면 이어서 동기화합니다. 중요한 거래 전에는 **동기화 완료** 표시를 확인하세요. 동기화 설정 창 아래의 **JSON 파일 백업**으로 파일을 따로 받아 둘 수도 있습니다.

## 시나리오 페이지 가정 저장 (`valuation.html`)

- 계산기의 가정을 바꾸면 현재 브라우저에 바로 저장되고, 페이지를 다시 열면 마지막으로 조정한 값이 복원됩니다. 위쪽 메뉴의 **가정 저장**에서 저장 상태를 볼 수 있습니다.
- **가정 저장** 창에서 이름을 붙여 여러 시나리오를 저장하고, 불러오거나 삭제할 수 있습니다. 같은 이름으로 저장하면 덮어쓸지 묻고, 저장하지 않은 조정값이 있을 때 다른 저장본을 불러오거나 **모든 가정 기본값으로**를 누르면 먼저 확인합니다.
- 기본값과 다른 입력만 저장합니다. 바꾸지 않은 기준 종가·시총 같은 값은 페이지의 기준 자료가 갱신되면 새 값을 따릅니다.
- 이 기기에는 브라우저 `localStorage`(`etf-planner-valuation-current-v1`, `etf-planner-valuation-scenarios-v1`, 삭제 기록 `etf-planner-valuation-deleted-v1`)에 저장합니다.

### 시나리오 가정 기기 간 동기화

- 따로 설정할 것은 없습니다. 메인 플래너에서 **기기 간 동기화**를 연결한 기기는 시나리오 페이지도 같은 비공개 데이터 저장소를 씁니다(같은 사이트라 저장소 이름과 토큰을 같이 읽습니다). 연결 상태는 **가정 저장** 창 아래쪽에서 볼 수 있습니다.
- 가정은 메인 플래너 기록(`etf-planner-data.json`)과 섞이지 않도록 같은 저장소의 `etf-planner-scenarios.json`에 따로 저장합니다.
- 페이지를 열 때, 가정 저장 창을 열 때, 45초마다, 탭으로 돌아올 때 다른 기기의 변경을 가져옵니다. 이름 붙인 저장·삭제는 바로, 슬라이더 조정은 5초 동안 더 바꾸지 않으면 올립니다(조정할 때마다 커밋이 쌓이지 않도록). 앱을 전환하거나 탭을 닫으면 기다리던 변경을 바로 올립니다.
- 충돌 확인 창은 없습니다. 여러 기기에서 만든 이름 붙인 저장본은 모두 합쳐지고(같은 저장본은 나중에 저장한 쪽), 한 기기에서 삭제한 저장본은 다른 기기에서도 지워집니다. 현재 조정값은 **가장 나중에 바꾼 기기**의 값을 따릅니다. 페이지를 열어 보기만 한 기기가 다른 기기의 조정값을 덮어쓰지는 않습니다.
- 공개 저장소이거나 저장소의 파일 형식을 알 수 없으면 올리지 않고, 이 기기에만 저장한 채 오류를 표시합니다.

## Claude ↔ Codex에서 이어서 수정하기

저장소 `main` 브랜치의 `index.html`이 코드 기준입니다. 변경된 부분과 관련 기능만 읽고 수정하면 대화마다 HTML 전체를 붙여넣을 필요가 없습니다. 개인 기록을 코드 기본값으로 옮기지 마세요. 기록은 코드와 별도로 비공개 데이터 저장소에서 불러옵니다. 수정 후에는 저장소 폴더에서 `node --test`로 동기화·달러선물·시나리오 가정 저장 동작을 확인하세요. 한 계정에서 두 도구로 수정할 때는 GitHub에서 최신 커밋을 당겨온 뒤 수정하고 배포하세요.
