# ETF 분할매매 플래너

공개 페이지: https://oax2310-blip.github.io/etf-planner/

코드는 공개됩니다. 실제 보유 종목, 수량, 메모, 손익은 `index.html`이나 이 저장소에 적지 마세요. 사이트에서 입력한 기록은 현재 브라우저에 저장됩니다. 구글 드라이브를 연결하면 같은 구글 계정의 다른 기기와 동기화됩니다.

## 구글 드라이브 연결 준비

이 저장소에는 구글 계정의 접근 권한이나 개인 기록이 포함되지 않습니다. 소유자가 한 번 다음 설정을 해야 합니다.

1. [Google Cloud Console](https://console.cloud.google.com/)에서 프로젝트를 만들고 **Google Drive API**를 사용 설정합니다.
2. [Google 인증 플랫폼](https://console.cloud.google.com/auth/overview)에서 앱 이름과 사용자 유형을 설정합니다. 앱이 테스트 상태라면 사용할 구글 계정을 **테스트 사용자**에 추가합니다.
3. **클라이언트**에서 유형 **웹 애플리케이션**의 OAuth 클라이언트 ID를 만듭니다. **승인된 JavaScript 원본**에 `https://oax2310-blip.github.io`를 추가합니다. `/etf-planner/` 경로는 원본에 넣지 않습니다.
4. 공개 사이트의 **구글 드라이브 연결**을 누르고 OAuth **클라이언트 ID** (`숫자-문자.apps.googleusercontent.com`)를 붙여넣은 후 **구글 계정 연결**을 누릅니다. 이 ID는 해당 기기의 브라우저에 저장됩니다. 다른 기기에서는 처음에 같은 ID를 입력해야 합니다.
5. 매 기기에서 같은 구글 계정을 고릅니다. 처음 연결할 때 기록이 서로 다르면 화면에 어느 기록을 남길지 선택할 수 있습니다. **JSON 백업** 버튼으로 먼저 사본을 받아 두세요.

매 기기에서 ID를 다시 입력하지 않으려면 `index.html` 상단의 `const GOOGLE_CLIENT_ID = "";`에 ID를 넣어 게시하면 됩니다. **클라이언트 시크릿이나 구글 액세스 토큰은 어떤 경우에도 공개 저장소에 넣지 마세요.** 클라이언트 ID는 공개용 식별자입니다.

## 저장 방식

- 입력할 때 현재 브라우저의 `localStorage`에 즉시 저장합니다. 구글 연결 중에는 잠시 뒤 구글 드라이브의 숨겨진 **앱 데이터 폴더**에도 저장합니다. 이 폴더는 일반 드라이브 파일 목록에서 보이지 않습니다.
- 연결 중에는 45초마다, 그리고 탭으로 돌아올 때 다른 기기의 변경을 확인합니다. 기기마다 별도의 구글 권한 동의가 필요하며, 구글의 브라우저용 접근 권한이 만료되면 **구글 계정 연결**을 다시 눌러야 합니다. 만료 중 기록은 기기에 남습니다.
- 다른 기기와 이 기기에서 모두 바뀐 경우 어느 기록을 사용할지 묻습니다. 선택하지 않으면 자동 업로드가 멈추고 기기에만 기록됩니다. 선택해 덮어쓴 기록은 그 기기에 복구용 JSON으로 따로 보관합니다. **동기화 설정 → 동기화 충돌 시 보관한 기록 내려받기**로 받거나 기존 **JSON 백업/복원**을 이용할 수 있습니다.
- 여러 기기에서 정확히 동시에 수정하면 구글 드라이브 파일의 최종 저장 순서에 따라 마지막 수정이 남을 수 있습니다. 중요한 거래 전에는 **동기화 완료** 표시를 확인하고 JSON 백업을 받아 두세요.
- GitHub Pages에는 웹 코드만 게시합니다. 구글 드라이브 기록은 이 저장소로 올라가지 않습니다. 다른 Google Cloud 프로젝트의 OAuth 클라이언트 ID로 바꾸면 이전 앱 데이터 폴더에 저장된 내용을 볼 수 없을 수 있으므로 기존 ID를 유지하고 JSON 백업도 보관하세요.

구글 설정 참고: [OAuth 웹 클라이언트 ID](https://developers.google.com/identity/oauth2/web/guides/get-google-api-clientid), [드라이브 앱 데이터 폴더](https://developers.google.com/workspace/drive/api/guides/appdata), [브라우저용 구글 권한의 만료](https://developers.google.com/identity/oauth2/web/guides/use-token-model).

## Claude ↔ Codex에서 이어서 수정하기

저장소 `main` 브랜치의 `index.html`이 코드 기준입니다. 변경된 부분과 관련 기능만 읽고 수정하면 대화마다 HTML 전체를 붙여넣을 필요가 없습니다. 개인 기록을 코드 기본값으로 옮기지 마세요. 웹페이지가 열리고 한 번 구글 계정에 연결되면 기록은 코드 수정과 별도로 드라이브에서 불러옵니다. 한 계정에서 두 도구로 수정할 때는 GitHub에서 최신 커밋을 당겨온 뒤 수정하고 배포하세요.
