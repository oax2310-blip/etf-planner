# 매매 플래너

개발·인수인계 지침: [AGENTS.md](AGENTS.md). Claude Code는 [CLAUDE.md](CLAUDE.md)를 통해 같은 지침을 읽습니다.

공개 페이지: https://oax2310-blip.github.io/etf-planner/

코드는 공개됩니다. 실제 보유 종목·수량·메모·손익은 코드나 이 저장소에 적지 마세요. 입력한 기록은 브라우저와, 연결했다면 내 GitHub **비공개 데이터 저장소**에만 저장됩니다.

## 기기 간 동기화 준비 (처음 한 번)

1. **데이터 저장소**: [github.com/new](https://github.com/new)에서 이름 `etf-planner-data`, **Private**, **Add a README file** 체크 → **Create repository**.
2. **토큰**: [Fine-grained 토큰 만들기](https://github.com/settings/personal-access-tokens/new)에서
   - **Repository access** → **Only select repositories** → `etf-planner-data`만 선택
   - **Permissions → Repository permissions → Contents** → **Read and write**
   - **Generate token** 후 값 복사(한 번만 보임).
3. 사이트 오른쪽 위 **동기화** 버튼에서 저장소(`oax2310-blip/etf-planner-data`) 확인 → 토큰 붙여넣기 → **연결**. 다른 기기도 처음 한 번 같은 토큰을 넣습니다.

## 규칙

- 시선·일선·주선·월선의 구간 매수는 시작선·⅓·⅔ 지점에서 사고 다음 선에 도달하면 별도로 삽니다. 달러선물·분할매수·재매수 설정과 점검 결과는 [가격 3등분 안내](docs/price-thirds.md)에 있습니다. 분할매도는 기존 방식입니다.
- 분할매수·분할매도는 회차의 **누적 체결** 칸에 실제 체결한 총주수만 넣습니다. 계획 10주 중 7주를 입력하면 자산에는 7주만 반영하고 **부분 체결 · 남은 매수(매도) 3주**로 남습니다. 추가 3주가 체결되면 누적 수량을 **10**으로 고칩니다(추가분만 자산에 반영). 체크는 잔량까지 전량 체결, 0 입력·완료 체크 해제는 해당 회차 체결과 자산 반영 취소입니다. 평가액만 있는 계획도 기준가·환율로 계획 주수를 내림해 계산합니다. 체결금액을 따로 입력하지 않으며, 배분 계산에 필요한 금액은 주수로 자동 계산합니다. 부분 체결은 완료 회차 수에 넣지 않고, 켜 둔 알림도 유지합니다.

- 토큰은 각 기기 브라우저에만 저장합니다. 코드·저장소·메모에 적지 마세요.
- 데이터 저장소는 반드시 비공개. 공개 저장소면 사이트가 업로드를 거부합니다.
- 기록을 사이트 저장소(`etf-planner`)에 저장하지 마세요. 저장할 때마다 GitHub Pages가 다시 게시됩니다.

## 저장 방식 (`index.html`)

- 입력 즉시 브라우저 `localStorage`에 저장하고, 연결 중이면 잠시 뒤 데이터 저장소의 `etf-planner-data.json`에 올립니다. 저장마다 커밋이 쌓이므로 예전 기록은 그 저장소 커밋 기록에서 봅니다.
- 열 때·45초마다·탭 복귀 시 다른 기기 변경을 확인합니다. 한쪽만 바뀌었으면 자동으로 맞추고, 아무것도 입력하지 않은 새 기기는 저장소 기록을 바로 가져옵니다.
- 양쪽 모두 바뀌었으면 어느 기록을 쓸지 묻습니다. 고르기 전에는 자동 업로드를 멈추고 이 기기에만 기록합니다. 덮어쓴 기록은 **동기화 설정 → 동기화 충돌 시 보관한 기록 내려받기**로 받고 **JSON 파일 복원**으로 되돌릴 수 있습니다.
- 올리는 순간 다른 기기가 먼저 저장했다면 덮어쓰지 않고 다시 확인합니다.
- 토큰이 만료되거나 틀려도 기록은 기기에 남습니다. 동기화 설정에서 새 토큰을 넣으면 이어집니다. 중요한 거래 전에는 **동기화 완료** 표시를 확인하고, 필요하면 **JSON 파일 백업**으로 따로 받아 두세요.

## 화면 모드

- PC(마우스·트랙패드)는 오른쪽 위 화면 모드 버튼에서 **기기 설정 따름**·**밝게**·**어둡게**를 고릅니다. 플래너와 시나리오 페이지가 같은 선택을 쓰고, 그 브라우저에만 저장됩니다(동기화하지 않음).
- 휴대폰·태블릿(터치)은 버튼이 없고 늘 기기 설정(밝은/어두운 모드)을 따릅니다.

## 시세 자동 채우기

- 플래너 화면 상단이나 **동기화 설정**의 **시세 즉시 불러오기**를 누르면, 자동 동기화를 기다리지 않고 데이터 저장소의 최신 시세 파일을 다시 읽어 현재가·기준가·환율과 분할매수 평가액에 반영합니다. 조회 중에는 버튼이 잠기며, 완료·오류와 마지막 수집 시각을 상단에 표시합니다. 새 시세 수집을 실행하는 버튼은 아니며, 수집 주기는 그대로입니다.
- 동기화를 연결하면 데이터 저장소의 `etf-planner-prices.json`(그 저장소 Actions **KIS 시세 수집**이 평일마다 갱신)을 함께 읽어 채웁니다. 읽기만 하고, 바뀌지 않았으면 다시 받지 않습니다(ETag).
  - 분할매도: 종료 기준선이 `60일선`·`20주선`·`25개월선`처럼 N일선·N주선·N개월선인 종료 기준가(국내 종목은 원화, 미국 종목은 달러 계획만). 시작 기준가(첫 매도 기준가)는 수정 창의 시작 기준선이 ‘직접’(기본)이면 직접 정하고, 일선·주선·개월선을 고르면 종료 기준가처럼 채웁니다. 현재 가격은 설명 줄에 표시만 합니다.
    - 종료 기준선은 수정 창에서 숫자와 일선·주선·개월선으로 고르고, 바꾸면 종료 기준가가 바로 바뀝니다. 시세 파일에 아직 없는 기준선은 함께 받은 종가로 같은 규칙(종가 단순이동평균)으로 계산하고, 봉이 모자라면 다음 수집 뒤 채워집니다.
    - 평가액은 보유 수량 × 현재가(달러 계획은 × 환율)로 계산해 화면에만 표시합니다(계획 화면은 남은 수량 기준). 수량 없이 평가액만 넣은 계획은 넣은 값을 씁니다.
    - 수정 창의 **매도 비중 (%)**(기본 100%)을 낮추면 보유 수량의 그 비중만 회차에 나눠 팔고 나머지는 남깁니다. 수량은 1주(비트코인은 0.00000001 BTC) 단위로 내림하고, 평가액만 넣은 계획은 평가액의 그 비중을 나눕니다.
    - 회차마다 같은 수량을 팝니다. 평가액만 넣은 계획(여러 추종 ETF처럼 주수로 넣기 어려운 경우)도 평가액을 저장할 때의 종목 시세로 수량을 환산해 같은 수량씩 나누므로, 회차 금액은 회차 기준가에 비례해 줄어듭니다. 저장할 때 시세가 없었거나 예전에 넣은 평가액은 첫 매도 기준가로 환산하고, 평가액을 다시 넣어 저장하면 그때 시세로 바뀝니다.
  - 분할매도 달러 계획 환율: 한국투자증권의 USD/KRW 현물 환율(`fx.USDKRW`). 달러선물 보유와 관계없이 원화 환산·평가액에 씁니다. 기존 시세 수집 주기마다 갱신되며, 은행·증권사의 실제 환전 적용 환율과는 다를 수 있습니다. 조회 실패 시 마지막 현물 환율을 유지하고, 현물 환율이 아직 없으면 계획의 마지막 환율을 그대로 둡니다.
  - 달러선물: 보유 근월물(계약 수가 있는 가장 가까운 월물)의 시선·일선·주선·월선 구간 기준가와 아직 안 산 계약의 3등분 매수가. 현재가는 구간 제목 옆에 표시만 합니다.
  - 재매수: 종목마다(왼쪽 **재매수 종목** 목록, **＋ 추가**) **종목 이름 옆 연필 → 종목 코드**를 넣으면(국내 종목 코드 또는 미국 종목 심볼) 현재가와 `25일선`~`150일선`, `25선`~`150선`(60분봉 차트의 25~150 이평선) 단계 기준가. N선은 수집 작업이 한국투자증권 분봉으로 60분봉을 만들어 계산하며, 처음에는 과거 봉을 몇 번의 수집에 나눠 받아 짧은 N선부터 채워집니다(그 전에는 직접 넣은 값 유지). 미국 종목은 가격·금액·보유 금액이 달러입니다. 비운 단계는 앞뒤 가격 사이를 고르게 나눈 추정치(≈)를 표시만 합니다(실제 이평선 값이 아니며 배분·알림에는 쓰지 않음). 옛 이름 `25분봉` 등은 `25선`으로 보이고 처음 고칠 때 바뀝니다. 새 종목 코드는 다음 수집(평일 장중 30분마다) 뒤 채워집니다.
- 비트코인: 시세 파일에 `BTC-USD`(Coinbase 달러 시세, 키 없음)가 늘 들어 있습니다. 데이터 저장소 수집 작업이 평일 수집 때마다 함께 받고, 저녁(19:40)과 주말(3시간마다)에는 비트코인만 받습니다. 일봉은 UTC 0시 기준이고 주봉(월~일)·월봉은 그 일봉을 묶어 만듭니다.
  - **동기화 설정** 창의 시세 줄에 비트코인 현재가(달러)와 기준일을 보여 줍니다.
  - **알림 → 직접 추가 알림**에서 종목 코드에 `BTC-USD`를 넣으면 다른 종목처럼 N일선·N주선·N개월선 알림을 받습니다(`BTC`는 미국 ETF 심볼이라 비트코인이 아님).
  - **분할매도**에서 종목 코드에 `비트코인` 또는 `BTC-USD`를 입력하면 통화를 **달러(USD)**로 자동 선택·고정하고, 현재가·자동 기준선·평가액과 연결 알림에 같은 비트코인 시세를 씁니다. `비트코인`으로 입력한 코드는 저장할 때 `BTC-USD`로 바꿉니다(`BTC`는 미국 ETF 심볼).
  - 비트코인 보유 수량은 소수점 8자리까지 입력하며, 회차별 수량을 0.00000001 BTC 단위로 균등 배분합니다. 합계는 보유 수량과 같고, 완료 체크 후 남은 수량도 같은 단위로 계산합니다. 주식은 기존처럼 정수 주수로 배분합니다.
  - 재매수 칸은 국내·미국 종목만 시세로 채웁니다(비트코인 제외).
- 시세가 우선입니다. 직접 고친 값은 그 칸의 시세가 다음에 바뀔 때 덮어씁니다(마지막으로 채운 값은 기록의 `auto`에 둠).
- 시세 기준일은 작게 표시하고, 3일 넘게 지났거나 마지막 조회에 실패했으면 주황색으로, 3일 넘게 지났으면 경고를 보여 줍니다. 수집 상태는 **동기화 설정** 창 아래에서도 봅니다.

## 달러선물 신저점 손절 후 재매수

- 손절은 특수한 상황이라 실행 전(체크 기록이 없을 때)에는 달러선물 화면 위에 **한 줄로 접어** 상태만 보여 줍니다(기준 미입력·실행 전·신저점 이탈·손절 시점과 현재 환율). **펼치기**로 기준을 입력하고, 첫 손절을 체크하면 계속 펼쳐 둡니다. 펼친 상태는 저장하지 않습니다.
- **달러선물 → 신저점 손절 후 재매수**에서 신저점 환율·손절 하단·이탈 전 계약 수·분할 횟수를 넣습니다. 신저점부터 하단까지 고르게 나눠 이탈 전 계약의 최대 50%만 손절합니다. 홀수 계약은 절반을 내림하고, 회차는 손절 목표 계약 수 이하로 줄입니다. 한 회차뿐이면 하단에서 손절합니다.
- 이탈 전 계약 수는 처음 입력할 때 고정합니다. 실제 손절 후 보유 월물을 수정해도 손절 목표는 바뀌지 않습니다. 손절을 체크하면 예정 수량·환율이 기록되므로 실제 체결 수량·환율로 맞추세요. 실제 수량을 바꾸면 남은 회차는 절반 한도까지 다시 배분합니다. 체결 기록이 생긴 뒤 손절 기준은 **체크 기록 초기화** 후 변경합니다.
- **재매수**는 기존 **재매수** 화면과 같은 규칙입니다(아래 **손절 후 재매수 배분** 참고). 기준은 **평균 손절 환율**(실제 손절 체결 환율의 계약 수 가중평균)이고, 판 계약을 정수로 나눕니다(단계마다 먼저 나눈 뒤 단계 안에서는 앞 회차부터). 회차를 체크하면 회차 환율로 기록하며, 부분 체결은 체크 후 실제 계약 수·체결 환율로 수정합니다.
- 재매수를 시작하면 남은 손절은 멈추고, 판 계약 수까지만 재매수합니다. 계약 수를 복원하는 계획이며 선물 매도 대금을 현금 재매수 예산으로 계산하지 않습니다. 예전 '손절 환율 복귀' 방식으로 체크한 재매수는 첫 미완료 반등 단계에 합쳐 보여 주고, 처음 고칠 때 그 단계 기록으로 옮깁니다.
- 설정·체결 기록·알림은 `futures.rebuy`로 기존 비공개 동기화·JSON 백업에 포함됩니다. 화면을 보기만 하면 새 필드를 만들지 않습니다. 보유 근월물의 현재 환율·일선·N선(60분봉, 한국투자증권이 묶은 08:45 기준 60분봉) 기준가는 기존 시세 파일로 채우며, 신저점·하단은 직접 정합니다.
- 회차·재매수 가격 옆에서 알림을 켤 수 있습니다. 체크는 이 계획의 기록용이며 실제 주문은 증권사에서 실행합니다. 기존 보유 월물·누적 정산손익은 계좌 기준으로 직접 수정하세요.

## 손절 후 재매수 배분 (재매수 화면·달러선물 공통)

- 기준은 **평균 손절가**(손절 금액 ÷ 손절 수량, 달러선물은 평균 손절 환율)입니다.
- 단계마다 **다음 단계 가격까지 3번**으로 나눈 회차 가격(단계 가격, ⅓ 지점, ⅔ 지점)을 만들고, 그중 **평균 손절가 이하인 회차**에 손절 금액(계약)을 똑같이 나눕니다. 대상 단계는 첫 단계(기본 25선)부터 끊기지 않고 이어진, 기준가가 평균 손절가 이하인 단계이며 상한은 없습니다.
- 예(평균 손절가 10,000원, 25선 9,700 · 32선 9,850 · 42선 10,150원): 25선 1·2·3차(9,700 · 9,750 · 9,800원)와 32선 1·2차(9,850 · 9,950원)에 5분할, 32선 3차(10,050원)는 평균 손절가 위라 사지 않습니다. 다음 단계 가격을 모르거나 더 낮으면 그 단계는 1차만 있습니다. 달러선물 계약은 회차에 고르게 흩습니다(3계약 5회면 1·0·1·0·1).
- 평균 손절가 이하 회차가 없으면(첫 단계가 평균 손절가보다 높음·기준가 없음) 첫 단계 1차(25선 기준가)에서 한 번에 삽니다. 2·3차는 1차보다 비싸므로 사지 않습니다. 기준가를 비운 단계에서 끊으며, 빈 단계의 추정치(≈)와 거기서 나온 회차 가격은 표시에만 쓰고 배분·알림에는 쓰지 않습니다.
- 회차 계획(어느 회차에서 살지)은 첫 재매수를 체크할 때 고정합니다(그 뒤 이평선이 움직여도 바뀌지 않음). 회차 가격은 이평선을 따라 움직입니다. 재매수 체크를 모두 풀거나 체크 기록을 초기화하면 다시 짭니다. 산 회차를 빼고 남은 금액은 계획의 남은 회차에 똑같이 나눕니다.
- 화면에서 회차는 단계 이름 뒤 작은 번호 칩으로 표시합니다(25선 [1]·[2]·[3], 산 회차는 초록, 사지 않는 회차는 회색). 휴대폰 알림은 글자만 보내므로 '재매수 25선 2차'처럼 옵니다.
- 재매수 기한은 따로 두지 않습니다. 남은 금액마다 살 회차 가격이 있어 가격이 오르면 회차 신호가 먼저 옵니다. 예전 단계 통째 체크 기록은 그 단계를 한 번에 산 것으로 봅니다.

## 휴대폰·PC 매매 기준 알림

- 각 화면의 가격 옆 **알림 ON/OFF**로 기존 기준을 켭니다. 분할매도 첫 매도·회차별 매도, 분할매수 회차(이동평균선 돌파 회차·목표가는 회차 가격 이상, 직접 입력은 상승 계획이면 이상·하락이면 이하), 달러선물 선별 도달·2·3차 매수, 재매수 신저점 이탈·회차별 손절·단계별 재매수(단계 안 1·2·3차)를 연결하며, 종류별 **전체 ON/OFF**도 있습니다. 첫 매도와 1회차는 같은 설정입니다.
- 알림 기준가는 계획 수정과 새 시세에 따라 자동 반영됩니다. 완료 회차·단계, 재매수가 시작된 뒤의 남은 손절은 제외합니다. 재매수 단계 알림을 켜면 그 단계의 1·2·3차 회차 가격을 모두 알립니다. 재매수 단계는 실제 배분 금액과 입력된 기준가가 있는 경우만 발송하며 빈 가격의 추정값은 사용하지 않습니다.
- 계획 외의 기준선은 **알림 → 직접 추가 알림 (선택) → 추가**에서 별도 등록합니다. N일선·N주선·N개월선과 근접 허용 범위(기본 ±0.5%)를 저장하며 매매 계획 없이 알림만 등록한 종목도 수집합니다. 비트코인은 종목 코드에 `BTC-USD`를 넣습니다.
- 동기화가 연결된 안드로이드 휴대폰이나 PC(Chrome·Edge·Firefox·Safari)에서 **알림 → 알림 받기**를 한 번 누르고 브라우저 알림을 허용하면, 사이트를 닫아도 웹 푸시를 받습니다. 휴대폰과 PC를 함께 연결하면 같은 알림이 둘 다에 옵니다. 각 기기에서 따로 연결하고 **이 기기 알림 해제**로 해제합니다.
- 도착한 알림을 누르면 해당 종목의 분할매도·분할매수·재매수 화면이나 달러선물 화면으로 바로 이동합니다. 직접 추가한 기준선 알림은 같은 종목의 매매 계획을 열고, 계획이 없으면 그 알림 규칙을 펼칩니다. 새 기기에서는 동기화로 기록을 받은 뒤 해당 종목을 찾습니다. 기존에 연결한 기기는 플래너를 한 번 열면 이동 기능이 적용됩니다.
- PC는 보통 브라우저가 켜져 있을 때 받고(플래너 탭은 닫아도 됨), 꺼져 있던 동안의 알림은 다시 켤 때(최대 24시간) 옵니다. Windows에서 브라우저를 닫아도 받으려면 Edge로 연결하고 Edge 설정 → 시스템 및 성능의 ‘닫혀 있을 때 백그라운드 확장 및 앱 계속 실행’을 켜 둡니다(Windows 10 20H1 이상). Chrome은 창을 모두 닫으면 꺼질 수 있습니다. Windows·Mac 알림 설정이나 방해 금지(집중 모드)에서 브라우저 알림이 꺼져 있으면 보이지 않습니다.
- 비공개 데이터 저장소의 시세 수집 작업이 화면과 같은 `prices.js`·`rebuy.js`·`trade-alerts.js`로 기준가와 배분을, `assets-calc.js`로 분할매수 회차 알림(자산 기록 `etf-planner-assets.json`)을 계산합니다. 매도·손절은 기준가 이하, 달러선물 이동평균선 매수·재매수는 기준가 이상, 신저점 이탈은 기준가 미만에서 한 번 알립니다. 가격이 반대편으로 돌아왔다가 다시 도달하면 다시 알립니다. 켰을 때 이미 조건에 해당하면 다음 수집 때 한 번 알립니다.
- 별도로 추가한 이동평균선 알림은 허용 범위 진입이나 위아래 통과를 감지하며 같은 범위에 머무는 동안 반복하지 않습니다.
- 미국 ETF를 추종하는 국내 ETF를 거래한다면 **알림 → 미국 기준 한국장 재알림**을 켭니다(기본 OFF). 밤사이 발생한 미국 종목 신호만 한국장 **오전 9시 45분쯤**에 기준별 한 번 더 받습니다. 새 신호가 없으면 보내지 않으며 OFF·삭제·완료 처리한 기준은 제외합니다. 주말·휴장일은 건너뛰고, 재알림에는 신호 당시 미국 시세를 표시합니다. 예약 실행이 늦어질 수 있습니다.
- 국내 주식·ETF는 **09:45부터 15:20 전까지** 알립니다. 시세 수집은 09:45 첫 조회 뒤 10:10~14:40 30분마다, 15:10 마지막 조회입니다. 09:10·09:40·15:40 예약 실행 자체를 없애 평일 3회 줄였고, 15:20 이후로 지연된 국내 장중 실행은 건너뜁니다. 16:40 종가 수집은 이동평균·평가액 갱신용으로 유지하며 국내 주식 알림은 보내지 않습니다. 국내 알림 재시도도 15:20에 끝납니다.
- 미국 장중 1시간 20분(23:10~03:10, 그 뒤는 06:40 마감 값) 수집 기준이며(비트코인은 저녁·주말에도 약 3시간마다) GitHub 예약 실행이 늦어질 수 있습니다. 수집 사이에 닿았다가 돌아오는 움직임은 놓칠 수 있습니다. 오래된 시세·조회 실패·봉 부족에는 새 알림을 만들지 않습니다. 달러선물은 주식과 거래 시간이 달라 국내 주식 알림 시간 제한을 적용하지 않습니다.
- 발송키는 기존 수집 환경에서 생성해 암호화해 보관합니다. 새 외부 서버나 텔레그램 계정은 필요 없습니다. 알림에는 종목·선·가격만 담고 보유 수량·손익·계좌정보는 넣지 않습니다. 발송 서버는 내용을 만들며 휴대폰의 잠금화면·PC 알림 센터에도 표시될 수 있습니다.
- 설정·기기 구독은 기존 비공개 기록에 저장합니다. 구독 정보도 개인 기록이므로 공개 저장소에 복사하지 마세요. 이전 버전의 플래너를 켜 둔 기기는 새로고침한 뒤 수정하세요.
- 자세한 연결·판정·복구 방법은 [기준선 알림 안내](docs/moving-average-alerts.md)에 있습니다.

## 시나리오 가정 저장 (`valuation.html`)

- 가정을 바꾸면 브라우저에 바로 저장되고 다시 열면 복원됩니다. **가정 저장** 창에서 이름 붙여 저장·불러오기·삭제합니다(같은 이름 덮어쓰기, 저장 안 한 조정값이 있을 때 다른 저장본 불러오기·**모든 가정 기본값으로**는 먼저 확인).
- 기본값과 다른 입력만 저장합니다. 바꾸지 않은 기준 종가·시총 등은 페이지 기준 자료가 갱신되면 새 값을 따릅니다.
- AI 구독사업은 연평균 결제계정 기준으로 부가세·수수료·추론비·기타 비용·연 고정비를 차감합니다. 원가 프리셋과 영업가치 가정도 같은 저장·동기화를 사용합니다. 기준과 해석은 [AI 구독사업 시나리오](docs/ai-subscription-scenario.md)에 정리했습니다.
- 기기 간 동기화는 따로 설정할 필요가 없습니다. 메인 플래너를 연결한 기기는 같은 저장소 이름·토큰을 읽어, 같은 데이터 저장소의 `etf-planner-scenarios.json`에 따로 저장합니다. 연결 상태는 **가정 저장** 창 아래쪽에서 봅니다.
- 열 때·가정 저장 창을 열 때·45초마다·탭 복귀 시 가져옵니다. 이름 붙인 저장·삭제는 바로, 슬라이더 조정은 5초간 더 바꾸지 않으면 올리고, 앱 전환·탭 닫기 시 기다리던 변경을 바로 올립니다.
- 충돌 확인 창은 없습니다. 이름 붙인 저장본은 모든 기기 것을 합치고(같은 저장본은 나중 저장 우선), 삭제는 다른 기기에도 반영됩니다. 현재 조정값은 가장 나중에 바꾼 기기를 따르며, 보기만 한 기기가 덮어쓰지는 않습니다.
- 공개 저장소이거나 파일 형식을 알 수 없으면 올리지 않고 이 기기에만 저장한 채 오류를 표시합니다.

## 분할매수 (`index.html`)

플래너 탭 줄의 **분할매수**에서 등록한 자산 배분 종목을 골라 목표 비중까지 나눠 사는 계획을 관리합니다. 종목은 창 위 검색칸에서 이름·종목 코드·그룹·소분류로 찾습니다(띄어 쓴 낱말이 모두 들어간 종목, Enter는 첫 종목). 이미 계획이 있는 종목을 고르면 그 계획을 엽니다. 종목 이름·목표 변경과 그룹 이동이 그대로 연결됩니다. 회차를 체크하면 자산 배분 보유량에도 더합니다(아래 **자산 배분 연동**, ‘비중 조정 완료’는 바꾸지 않음). 종목을 삭제하면 그 종목의 분할매수 계획도 함께 삭제됩니다.

- **이동평균선 돌파(기본)**: 매수 목표 비중(비우면 종목 목표 비중)·목표 가격·단계(60분봉 + 일봉 / 일봉만 / 60분봉만)를 넣습니다. 총 매수 금액 = 목표 비중 × 기준 총자산 − 지금 평가액(이미 체결한 금액이 있으면 더함 — 매수한 수량을 자산 배분 보유량에 반영했다고 봄)이고, 직접 고칠 수 있습니다(**다시 계산**으로 되돌림).
  - 단계는 재매수 기본 단계와 같은 60분봉 25선~150선 → 일봉 25일선~150일선입니다. 단계마다 다음 단계 가격까지 3번(단계 가격·⅓·⅔ — 다음 단계가 더 낮거나 없으면 1차만) 나눈 회차 중 **목표 가격보다 낮은 회차**와 마지막 **목표가** 회차(목표 가격)에 같은 금액씩 삽니다. 현재가가 회차 가격 이상이면 도달입니다.
  - 미체결 회차 가격은 시세 파일의 이동평균을 따라 움직입니다. **매수 8주**처럼 회차 예산과 표시 가격으로 살 수 있는 수량을 내림해 표시합니다. **누적 체결** 수량을 입력하면 실제 체결량만 자산 배분에 반영하고, 체크하면 표시한 수량까지 전량 체결합니다. 첫 체결 때 회차의 원래 계획 수량·가격을 고정하므로 시세가 바뀌거나 단계가 사라져도 잔량은 유지됩니다. 잔량 예산을 먼저 남겨 두고 나머지 예산만 지금 이동평균 기준 새 회차에 나눕니다. 예산으로 1주도 살 수 없거나 환율·가격이 없으면 체결 입력·완료 체크가 비활성화됩니다. 시세가 없는 단계는 건너뛰고, 이동평균이 하나도 없으면(계획을 처음 만든 직후) 목표가 회차만 보입니다.
  - 부분 체결·완료 회차의 **누적 체결 주수**만 카드에서 고칩니다. 입력칸과 카드의 체결·잔량 요약은 주수이며 체결금액 입력은 없습니다. 주수를 고치면 자산 배분 보유량과 배분 계산용 금액을 자동으로 맞춥니다. 계획 수량까지 체결해야 완료하며, 완료 후 수량을 줄이면 부분 체결로 돌아갑니다. 수량 없는 옛 체결은 자산 배분에 이미 반영된 주수를 보여 주며, 주수를 입력·수정할 때 기록에 저장합니다.
  - 데이터 저장소 수집 작업이 이 종목의 전체 시세(일봉 N일선)와 60분봉 N선을 계획 종목처럼 받습니다. 저장한 뒤 다음 수집(장중 30분마다)부터 채워지고, 60분봉 긴 선은 과거 봉을 받는 동안 며칠 걸릴 수 있습니다. 시세 종목 코드가 있는 종목만 쓸 수 있습니다.
- **직접 입력**: 회차별 매수 가격·계획 주수·예정일·조건·예정액(만원)을 정합니다(가격 × 수량으로 예정액 계산). 체결은 누적 주수만 입력합니다. 주수 없는 옛 회차도 예정액·가격·환율이 있으면 계획 주수를 내림해 표시합니다. 계산할 수 없으면 계획에 주수를 넣습니다. 부분 체결도 배분 계산에 포함하고, 미체결 잔량만 남은 예정액에 넣습니다. 체결 주수 정정은 카드에서 하고, 수정 창에서는 계획 기준을 유지합니다. 마지막 회차 가격이 첫 회차보다 높으면 상승(현재가 ≥ 회차 가격이면 도달), 아니면 하락(≤)으로 봅니다. 체결 기록이 있는 방식에서는 다른 방식으로 바꾸지 않습니다.
- 카드에는 현재가(시세 파일)와 다음 회차까지 남은 %를 보여 주고, 현재가가 닿은 미완료 회차를 **도달**로 표시합니다.
- **일반 추종 ETF 주수 환산**: **자산 → 자산 배분 → 종목 수정**에서 기존 기준 티커(예: 미국 ETF)는 유지하고 **실제 매수 ETF 코드**를 따로 넣습니다. 회차 예산(만원) ÷ 실제 ETF 원화 가격을 정수 주수로 내림해 **매수 주수·예상 금액·잔액**을 표시합니다. 직접 입력 회차의 가격·미체결 기준 수량은 기준 티커 단위이며, 예정액을 넣지 않았다면 기준 수량 × 기준가 × 환율로 예산을 환산합니다. 실제 ETF가 달러 가격이면 원화 예산을 환율로 나눕니다.
  - **이미 보유한 ETF의 매수 반영**: 해당 계좌·그룹의 기존 자산 종목을 수정하고, 분할매수 계획에서도 그 항목을 고릅니다. 카드·계획 창에 **매수 반영 대상(자산 배분 → 그룹 → 종목)**과 현재 보유량을 표시합니다. 체결분은 선택한 항목의 id에만 더하므로 같은 ETF 코드가 다른 계좌에 있어도 영향을 주지 않습니다. 보유 주수 없이 금액으로 관리하는 항목은 체결 금액을 더합니다. 추가 체결·취소는 최초 반영 기록에 저장한 항목을 그대로 수정·복원합니다.
  - 실제 ETF 가격은 자동 시세를 우선합니다. 시세가 없으면 종목 수정 창의 **매수 ETF 현재가**를 직접 넣고, 둘 다 없으면 체결 입력·체크를 비활성화합니다. 가격·환율 기준도 카드에 표시합니다. 수집 작업은 기준 티커의 이동평균을 유지하면서 실제 ETF의 현재가도 장중에 수집합니다.
  - 보유 수량과 누적 체결 수량은 실제 ETF 주수입니다. 첫 체결 때 실제 ETF 코드·가격·통화·계획 주수를 고정해 부분 체결 잔량을 유지하고, 취소하면 기준 수량 입력과 자산 반영을 되돌립니다. 기준 가격 도달·휴대폰 알림은 기존 기준 티커를 계속 사용합니다. 실제 ETF 코드를 비운 기존 기록의 계산은 그대로입니다.
- 휴대폰 알림: 카드의 회차 옆 **알림 ON**(또는 카드 위 **전체 ON**)을 켜면 같은 도달 기준으로 알립니다(아래 **휴대폰·PC 매매 기준 알림**, 라벨 `분할매수 25선 2차`·`분할매수 목표가`·`분할매수 3차`). 자산 배분에서 그 종목에 시세 종목 코드가 있고 계획 통화가 그 시장 통화와 같아야 합니다(미국 심볼은 달러). 이동평균선 돌파 회차는 이평선이 움직여도 같은 알림으로 이어지고, 직접 입력에서 알림을 켠 종목은 수집 작업이 장중 실행마다 현재가를 받습니다.

기존 자산 기록의 종목별 `buyPlan`을 그대로 사용하므로 데이터 이전 없이 연결됩니다. `js/assets-store.js`에서 자산 페이지와 같은 저장·동기화를 사용하며, 플래너의 동기화 창에서도 **분할매수·자산 JSON 백업·복원**과 보관한 복구 기록을 내려받을 수 있습니다.

## 자산 배분 연동 (분할매도·재매수·분할매수 ↔ 자산 배분)

**기준 ETF를 따르는 보유 ETF 매도**: 분할매도 화면의 **실제 매도 계좌 · ETF**에서 ISA·연저펀 등 자산 배분에 등록한 계좌·그룹을 고릅니다. 해당 계좌에서 기준 티커와 연결한 보유 ETF가 하나이거나 보유 ETF가 하나면 자동 선택하고, 여러 후보가 있으면 보유 종목을 고릅니다. 기존 자산 항목의 ETF 코드를 자동으로 읽으므로 매도 계획에 코드를 다시 입력하지 않습니다.

회차에는 **기준 ETF 2주 → 선택한 계좌의 실제 ETF N주 매도**를 표시합니다. N = 기준 주수 × 기준 ETF 현재가 × 환율 ÷ 실제 ETF 현재가를 정수로 내림한 값이며 보유량을 초과하지 않습니다(같은 종목을 직접 팔면 기준 주수 그대로, 기준 현재가가 없으면 회차 기준가 사용). 실제 ETF 가격·필요한 환율·보유량을 확인할 수 없으면 체결을 막습니다. 누적 체결 칸에는 **실제 ETF 주수**를 입력하고 선택한 기존 자산 항목에서만 차감합니다. 부분 체결 뒤에는 가격·환율·계좌가 바뀌어도 당시 ETF와 계획 주수를 유지하고, 취소하면 원래 계좌의 보유량을 복원합니다. 계좌를 바꿔도 이미 체결한 회차는 원래 계좌에 남고 새 회차부터 새 계좌를 사용합니다. 매도 기준선·도달 알림은 기준 티커를 유지하며 수집 작업은 선택한 실제 ETF 현재가도 장중에 갱신합니다.

플래너 화면과 자산 현황의 자산 배분을 종목 코드로 연결합니다.

- 연결: 계획·재매수 종목과 종목 코드가 같은 자산 배분 종목(계좌)입니다(대소문자·국내 코드 앞 `A` 무시, `비트코인` = `BTC-USD`). 분할매수는 계획이 붙은 종목도 포함합니다. 추종 ETF 분할매수는 계획을 붙인 자산 항목에만 반영하며, 같은 ETF를 여러 계좌에 보유했다면 계획을 만들 때 해당 계좌의 기존 종목을 고릅니다. 종목 코드가 없거나 같은 코드가 없으면 지금처럼 체크만 합니다.
- 계획 화면 제목 아래 **자산 배분** 줄: 연결 계좌 수·평가액, 현재/목표 비중, 목표까지(목표 초과) 금액. 목표는 연결 종목 목표의 합, 없으면 연결 종목이 한 그룹의 전부일 때 그 그룹 목표 `(그룹)`입니다.
- 보유량 가져오기: 분할매도 수정 창(매도 체크 전)·재매수 기준 입력(손절·재매수 체크 전)에서 연결 계좌의 보유량을 넣습니다. 모두 수량이면 수량 합, 아니면 평가액 합(만원 — 미국 종목 재매수는 달러로 환산).
- 체크하면 보유량 반영: 분할매도 회차·재매수 손절은 빼고, 재매수 회차·분할매수 회차는 더합니다.
  - 연결 계좌가 하나면 바로 반영하고 화면 아래에 결과를 잠깐 보여 줍니다. 여럿이면 **자산 배분에 반영** 창에서 계좌를 고릅니다 — 계좌 이름을 누르면 그 계좌로 모두, 여러 계좌로 나눴으면 칸을 고칩니다. 같은 계획에서 마지막으로 고른 계좌(재매수 회차는 손절한 계좌)가 먼저 선택돼 있습니다. **반영 안 함**은 체크만, **취소**는 체크하지 않습니다.
  - 양: 수량을 넣은 종목은 주(비트코인 0.00000001 단위), 금액만 넣은 종목은 지금 평가액 기준 만원. 분할매도는 누적 체결 주수 × 회차 기준가, 재매수는 기록한 수량 × 가격, 분할매수는 누적 체결 주수와 자동 계산한 금액입니다. 주수 없는 옛 매수·매도 계획도 회차 가격·환율로 계획 주수를 계산해 체결을 입력합니다.
  - 시세를 따라가는 금액 종목은 입력 금액 칸을 같은 비율로 바꿔 입력 대비 수익률을 유지합니다. 보유량은 0 아래로 내려가지 않고, 다 판 종목은 보유 수량 0(평가액 0)으로 남습니다.
  - 분할매수·분할매도는 체크 전부터 누적 체결 주수로 부분 체결을 입력합니다. 추가 체결·주수 정정은 기존 반영 기록을 맞춰 자산에는 차이만 반영하며, 금액은 자동으로 계산합니다. 재매수 손절·재매수 체결 수량·가격 정정도 같은 방식입니다.
- 체크를 풀면 반영한 양을 그대로 되돌립니다. 재매수 **체크 기록 초기화**는 되돌릴지 한 번 더 묻습니다. 계획·종목을 삭제해도 자산 배분은 그대로 둡니다(실제 체결).
- 반영 기록은 자산 기록(`etf-planner-assets.json`)의 `allocation.trades`에 부분 체결·완료 기록이 있는 동안 두고 자산 배분과 함께 동기화합니다. 자산 현황의 종목 수정 창에서 그 종목에 반영한 내역을 봅니다.
- 이 기능 전에 체크한 회차는 반영 기록이 없어 풀어도 자산 배분을 바꾸지 않습니다. 달러선물은 종목 코드가 없어 연결하지 않습니다.

## 자산 현황 (`assets.html`)

엑셀로 관리하던 자산 정리를 옮긴 페이지입니다. 플래너 탭 줄의 **자산**으로 들어갑니다(돌아갈 때는 오른쪽 위 **플래너**).

- **투자구성**(엑셀 분할 정리): 지역·자산 분류별 평가액과 현재·목표 비중, 목표까지 남은 금액·초과 금액을 한눈에 봅니다. 목표 비중은 종목 → 소분류 → 그룹 → 분류로 합산합니다. 하위 목표가 하나라도 있으면 그 합계를 쓰고, 전부 비어 있으면 기존 직접 입력한 목표를 씁니다. 상위 목표는 합산 중에는 직접 수정하지 않으며, 저장된 기존 목표는 계산만으로 바꾸지 않습니다.
- **자산 배분**(엑셀 Sheet2): 그룹·종목과 현금을 관리합니다. 금액은 만원, 모든 목표 비중은 직접 넣은 기준 총자산(비우면 종목 + 현금 합계) 대비입니다. 종목별에서 목표를 고치면 투자구성에도 자동 반영됩니다. ‘비중 조정 완료’는 직접 체크하는 작업 기록으로, 현재 비중이나 목표 도달을 자동 판정하지 않고 계산에도 영향을 주지 않습니다. 현금(원화·달러, 빼는 항목)은 따로 적고 달러는 현물 환율로 환산합니다.
  - 그룹 추가·수정 창의 **큰 분류**에서 **해외 · 중국**을 선택할 수 있으며, **해외 · 인도**가 있으면 바로 다음에 표시합니다. 중국 분류가 없는 기존 기록은 이 분류를 선택한 그룹을 저장할 때 추가합니다. 이전 **중국 · 주식** 기록도 기존 연결을 유지하며 **해외 · 중국**으로 표시합니다.
  - 기준 총자산은 억·만원으로 표시하고 그대로 수정할 수 있습니다. 숫자만 넣으면 기존처럼 만원 단위로 저장하며, 비우면 종목 + 현금 합계를 기준으로 씁니다.
