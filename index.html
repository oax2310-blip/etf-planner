저장된 계획

입력 내용은 이 기기에 즉시 저장됩니다. 구글 드라이브를 연결하면 다른 기기와도 동기화됩니다. JSON 백업도 주기적으로 보관하세요.

새 매도 계획

주식 수량을 입력하면 회차별 주수를 정수로 자동 분배합니다. 평가액을 입력하면 회차별 매도액을 계산합니다. 원하는 분할 비율은 ‘분할 횟수’로 조정하세요.

구글 드라이브 동기화

연결 중에는 변경 내용을 드라이브의 앱 전용 저장 공간에 자동 저장하고, 다른 기기에서 변경한 내용도 불러옵니다. 현재 기기의 기록은 계속 보관됩니다. 구글 권한이 만료되면 다시 연결해야 합니다.

최초 설정은 저장소의 README.md를 참고하세요. 사이트 소스에 ID를 등록하면 각 기기에서 다시 입력할 필요가 없습니다.

기록이 서로 다릅니다

어느 기록을 쓸지 선택하세요. 덮어쓰기 전 다른 기록은 이 기기에 복구용 JSON으로 보관합니다.
